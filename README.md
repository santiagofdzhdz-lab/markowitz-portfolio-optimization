# Markowitz Portfolio Optimization (Monte Carlo)

Portfolio optimization in Python based on Markowitz Modern Portfolio Theory.

## What it does
- Downloads historical stock prices with `yfinance`
- Runs Monte Carlo simulations of portfolios with random weights
- Calculates expected return, volatility and Sharpe Ratio for each portfolio
- Plots the efficient frontier and highlights the max-Sharpe (optimal) portfolio
- Reports the optimal weights, expected return and final portfolio value

## Tech stack
Python · pandas · NumPy · Plotly · yfinance · Google Colab

## How to run
1. Open `markowitz_monte_carlo.ipynb` in Google Colab
2. Runtime → Run all
